# ESP32 Face-Tracking Turret

A pan-and-tilt ESP32 turret capable of tracking a face while simultaneously providing a live Wi-Fi camera stream.

[ADD HERO IMAGE HERE]

## Why I Built It

I built this project for an Autodesk Instructables competition as an experiment in combining embedded control, computer vision, mechanical design, and wireless video streaming.

## What It Does

- Detects and tracks a face
- Controls a two-axis pan/tilt mechanism
- Streams live camera video over Wi-Fi
- Runs using an ESP32-based embedded system
- Uses a custom 3D-printed mechanical assembly

## Build

The system combines an ESP32 camera platform with servo-controlled pan and tilt axes. The mechanical components were designed and 3D printed, then iterated to achieve reliable movement and camera positioning.
